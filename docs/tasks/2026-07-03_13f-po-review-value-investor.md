# 13F 功能 PO 全面评审(价值投资者视角)

**日期:** 2026-07-03 · **评审人:** PO(以顶级价值投资者视角)
**范围:** 全部 13F 后端服务(25 模块)、Oracle's Lens 打分层(9 模块)、前端用户面与管理面、86 家管理人种子数据。
**产出:** 本评审 + 下一期开发包 "13F investor workflow" 三张票(见 §5)。

---

## 1. 功能盘点(评审时点的事实)

- **管线**:EDGAR 每日同步 → filing 封面解析(修正案/机密/覆盖类型)→ 两阶段持仓解析(ParseRun 原子切换 + 指纹幂等)→ CUSIP 富化(时间区间治理 + 公司行动人工确认)→ 季度变动预计算(置信度分级)→ 质量检查 → 修正案工作流 → 受控重解析 → 历史回填(pre-2023 风险闸)。
- **打分**:signal_weighted(管理人权重 × 仓位信号)、conviction 五分量、distinctive consensus(只降不升)、全链路 caveat 传播、`score_version` 版本化。
- **管理人宇宙**:86 家人工确认,手写分类理由,V2 taxonomy(style_primary 八类),含诚实的 V1 纠错记录(Tiger Global 误分类等)。
- **用户面**:Oracle's Lens 漏斗(筛选→排名→气泡→钻取抽屉→Value Line 溯源)+ Watchlist×13F 四列与行级抽屉。**管理面**:6 页 + 50 余端点。

## 2. 投资价值判定

**判定:地基罕见地好,缺投资者工作流的最后一层。** 三个差异化强项:

1. **管理人质量加权**(1.0 → 0.1)+ 行为学分类 + admin 覆盖——免费 13F 产品几乎都等权展示,这是投资上正确且稀缺的设计。
2. **Caveat 诚实性**——NT 断档≠清仓、combination 无分母、修正案未决 delta 不可信、CUSIP 换号伪装清仓,全部显式建模传到 UI。错误信号比没有信号更贵。
3. **Watchlist 集成**回答投资者每天真正的问题("我的持仓里聪明钱在进还是出")。

**13F 的结构性洞察**(评审的判断基准):45 天滞后杀死快钱信号,杀不死低换手/高集中管理人的信号——13F 的 alpha 集中在:①精选管理人的新建仓;②多位独立优质管理人同季收敛;③长期持有者的清仓;④拥挤度作为风险信号。

## 4. 交互评审

**好**:研究漏斗动线清楚;watchlist 列信息密度克制正确;caveat 徽章无处不在;默认值懂行(superinvestor_only、min_holders=3)。
